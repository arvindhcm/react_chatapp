# react_chatapp
responsive web app made using react 19, tailwind css 4, vite and feather icons, with 5 switchable color themes from [Happy Hues](https://www.happyhues.co/).

checkout the project here =>   [React ChatApp Demo](https://arvindhcm.github.io/react_chatapp/dist)

## Development

Requires Node 20.19+ or 22.12+.

```sh
npm install
npm run dev      # dev server at http://localhost:8080
npm run build    # production build into dist/ (served by GitHub Pages)
```
